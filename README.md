# KT Noise Cancellation Browser Extension

Developed and sponsored by **Kawerify Tech** ([kawerifytech.com](https://kawerifytech.com)).

## Features
- **Zero Server Uploads**: 100% local, on-device audio processing.
- **Dynamic DSP Pipeline**: High-pass filter, noise gate, compressor, and volume booster.
- **MV3 Architecture**: Compliant with Manifest V3 using background workers and offscreen documents.
- **Cross-Browser Support**: Built with WXT.

## Development

```bash
# Install dependencies
npm install

# Run dev mode
npm run dev

# Build for production
npm run build
```
